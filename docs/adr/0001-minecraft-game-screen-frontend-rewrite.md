# 0001. 前端从零重写为 Minecraft 游戏界面

日期：2026-07-29

## 状态

已接受

## 背景

现有前端（React 19 + Vite + Tailwind + Radix + recharts 的传统 dashboard）被要求完全重写，目标是"看起来就像在 Minecraft 游戏里一样"。

## 决策

1. **从零重写**：`frontend/src` 现有代码零继承；技术栈保持 React 19 + Vite + TypeScript
2. **游戏界面隐喻**：信息架构按 MC 游戏界面流组织，而非"MC 皮肤的 dashboard"
3. **Java 经典视觉语言**：对标 Java 版 1.12 前 programmer art（泥土背景、灰石按钮、像素字体）
4. **素材合规**：字体用开源复刻（拉丁像素字体 + OFL 中文像素字体），贴图由构建期脚本程序化生成，不使用任何官方游戏资源

## 理由

- 游戏界面隐喻是"像在游戏里"的唯一忠实实现；皮肤方案只是"MC 主题后台"
- Java 经典视觉辨识度最高，且贴图简单到可程序化复刻，规避 Mojang 素材版权
- 后端 API 契约不变，重写仅限前端

## 后果

- 图表、表格、表单等数据密集组件需要重新发明 MC 风格表达（recharts/Radix 均不可用）
- 旧前端整体删除，一次性切换，无并行运行期
- 中文字体必须选开源像素字体（MC 官方的 Unifont 方案有 GPL 传染性顾虑）
