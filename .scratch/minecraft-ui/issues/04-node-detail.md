# 04 节点详情：服务器信息 GUI 面板

Status: ready-for-agent
Blocked by: 03
Spec: ../spec.md

## 目标

`/nodes/:nodeId` 实现为物品栏边框式 GUI 面板，展示单个节点的完整监控信息。

## 范围

1. `McPanel` 容器排版：节点名、地址、版本、MOTD、在线状态大头区块
2. 复用 03 的图表：该节点人数历史、延迟趋势、在线率热力条
3. 当前在线玩家列表（TAB 式名单，像素字体，无头像）
4. 时间范围切换（24h/7d/30d，`McTabs` 或 `McButton` 组）
5. 从多人列表（02）点击条目进入的动线打通

## 验收

- 浏览器冒烟：从列表点击进入详情，数据与 API 一致
- 图表与统计屏同组件渲染，无重复实现
- 时间范围切换触发正确查询
- 双语词条完整
