# 08 登录页 + 音效 + 昼夜氛围

Status: ready-for-agent
Blocked by: 01
Spec: ../spec.md

## 目标

`/login` 实现为 MC 登录框；全站接入按钮点击音与昼夜氛围。

## 范围

1. `/login`：居中 `McPanel` + `McInput`（用户名/密码）+ 大按钮；首次运行初始化管理员流程保留（后端能力不变）
2. **音效**：CC0 按钮点击音接入 `McButton`；全局静音开关（localStorage 持久化，管理屏可关）
3. **昼夜氛围**：按本地时间计算日周期系数 → CSS 变量驱动背景亮度/色调（泥土背景叠加深色蒙版）；无 UI 切换
4. 全局导航：各页面"返回列表"动线统一（MC 风格"完成"按钮）

## 验收

- 浏览器冒烟：登录/初始化流程走通，错误密码有 MC 风格报错
- 按钮点击音可听，静音开关生效且刷新后保持
- 昼夜：手动改系统时间或用测试钩子验证色调变化
- 双语词条完整
