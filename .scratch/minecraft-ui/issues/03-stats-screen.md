# 03 统计信息屏 + canvas 像素图表

Status: ready-for-agent
Blocked by: 01
Spec: ../spec.md

## 目标

`/stats` 路由实现为 MC 统计信息屏，并产出全站复用的 canvas 像素图表组件。

## 范围

1. **图表基件**（`components/mc/charts/`）：canvas 渲染、关闭抗锯齿、块状像素；时间序列折线/柱状、坐标纸网格、hover 十字线 + `McTooltip` 读数；调色板：草绿=在线、红石红=离线、金=警告
2. `McHeatBar`：在线率热力，快捷栏格子样式（每格=一时间段，绿→红渐变）
3. `McProgressBar`：经验条样式（用于占比类指标）
4. 统计屏页面：全局指标（总节点、在线节点、总玩家、平均延迟）+ 人数历史图 + 延迟趋势图 + 各节点在线率热力
5. 数据：沿用现有 `/api/web/*` 接口 + react-query

## 验收

- 浏览器冒烟：图表渲染为明显像素风（非平滑矢量），数值与 API 一致
- hover 读数正确；热力格子颜色分档正确
- 图表组件被 04（节点详情）复用——导出接口设计好
- 双语词条完整
