# 02 多人游戏列表（落地页）

Status: ready-for-agent
Blocked by: 01
Spec: ../spec.md

## 目标

`/` 路由实现为 MC 多人游戏列表，照抄 Java 经典版视觉：这是用户打开网站看到的第一屏。

## 范围

1. `McMotd` 组件：MOTD `§` 格式化代码渲染（颜色、粗体、斜体、下划线、删除线、乱码动画）
2. `McServerEntry` 组件：服务器图标（无图标时用默认泥土/unknown_server 式占位）、名称、MOTD 两行、人数 `x/y`、ping 信号格（绿满格→红空格分档）、离线状态（红色 "无法连接" 式提示）
3. 列表页：节点按组过滤（顶部 `McTabs` 标签栏）、WebSocket `poll_complete` 触发刷新
4. 点击条目 → 跳转节点详情（`/nodes/:nodeId` 占位即可，03/04 填充）
5. 空态/加载态：MC 风格文案（如"正在扫描局域网世界..."式加载提示）

## 验收

- 浏览器冒烟：真实数据库下列表渲染正确，MOTD 颜色码正确渲染
- 在线/离线状态视觉区分明确；ping 分档正确
- 组切换过滤生效；WS 推送后数据自动刷新
- 双语词条完整
